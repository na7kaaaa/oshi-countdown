# oshi-countdown

推しの誕生日🎂と次のイベント⏳をカウントダウンできる、推し活向けの小さなNotionウィジェットです。

毎日Notionを開くたびに、推しまでの「あと◯日」がひと目でわかります。

## 特徴

- 推しの誕生日までの日数を自動計算（毎年の「次の誕生日」を自動で判定）
- ライブ・イベントなど複数の予定を登録して、一番近いものを自動表示
- データはブラウザの`localStorage`に保存されるので、サーバー不要・登録不要
- 1時間ごとに自動更新

## 使い方

### 1. GitHub Pagesで公開する

このリポジトリの **Settings → Pages** から、Sourceを`main`ブランチに設定してください。
数分後に以下のようなURLが発行されます。

```
https://<ユーザー名>.github.io/oshi-countdown/
```

### 2. Notionに埋め込む

Notionのページで `/埋め込み` ブロックを追加し、発行されたURLを貼り付けるだけです。

### 3. 日付をカスタマイズする

ウィジェット右下の **「日付を編集」** ボタンから、以下を自由に変更できます。

- 推しの呼び名
- 推しの誕生日（`YYYY-MM-DD`形式、年は仮でOK）
- イベント一覧（`イベント名@YYYY-MM-DD`の形式で複数行入力可）

入力した内容はブラウザに保存され、次回開いたときも保持されます。

## カスタマイズしたい人向け

`index.html`内の`DEFAULT_DATA`を書き換えると、初回表示のデフォルト値を変更できます。

配色は`<style>`内の`:root`にあるCSS変数（`--accent`など）から調整可能です。
